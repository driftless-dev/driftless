Driftless field notes

Guides for when the model, the labels, or the eval change.

Each post is one situation: a retired model, cheaper inference, new gold labels, RAG, or an agent. If you already know your app type — classifier, summarizer, RAG, or agent — start from the map below.

New to Driftless? Start with the four-row demo (no API key). A failing compare is expected: the cheap model scored 0.000, you needed at least 0.9. --generator none makes no prompt edits (blocked). --generator fixture applies the bundled patch and can pass. support-classifier-svc in some posts is an optional 290-row testbed, not that demo.
